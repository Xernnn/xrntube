            Sync across any browser

            chrome.storage.sync only bridges browsers signed into the same account (Chrome↔Chrome, Firefox↔Firefox). To carry your blocklist between vendors — say Chrome on the desktop and Firefox on Android — connect a private GitHub Gist. It's free and runs no server.
